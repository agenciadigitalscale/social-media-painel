# Find Skills

Use this skill when you want to search for other skills, compare capabilities, or choose the best skill for a task.

## Purpose

- Discover available skills by keyword or task description
- Recommend skills based on the user’s goal
- Explain which skill to use for design, coding, testing, or deployment

## How to use

- Ask: `Use the find-skills skill to find a skill for React UI design.`
- Ask: `Which skill should I use to improve backend TypeScript code?`
- Ask: `Find me skills for Cloudflare Pages, design systems, and performance testing.`

## Behavior

- Search skill names and descriptions
- Return a ranked list of relevant skills
- Provide a short recommendation for the best match
- Suggest follow-up skills for adjacent needs
