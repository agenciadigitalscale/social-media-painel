# Agent Customization

Use this skill when you want to configure or extend the Copilot Chat assistant behavior via custom prompts, skill files, or repository-specific instructions.

## Purpose

- Create or edit `.agent.md`, `SKILL.md`, `prompt.md`, and similar files
- Adjust local skill behavior for workspace-specific coding conventions
- Fix or improve skill installation and detection

## How to use

- Ask: `Use agent-customization to create a new skill for Cloudflare deployment.`
- Ask: `Use agent-customization to fix the prompt in this skill file.`
- Ask: `Use agent-customization to make a custom rule for TypeScript and MUI components.`

## Behavior

- Inspect customization files before editing
- Preserve existing structure and metadata
- Write clear, concise skill descriptions and rules
- Avoid changing unrelated files or logic
